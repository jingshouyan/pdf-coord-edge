# PDF 坐标查看器（Edge 扩展）

在 Edge 中打开 PDF 时，**以每页左下角为原点 (0,0)**，实时显示鼠标位置的坐标，单位 **pt**（1 pt = 1/72 英寸）。

目录：`tools/pdf-helper/pdf-coord-edge/`

```
manifest.json      MV3 清单
background.js      接管 Edge 打开的 .pdf，改由查看器渲染
viewer.html/css/js 查看器与坐标测量逻辑
popup.html/js      工具栏弹窗（接管开关）
lib/pdf.min.js     pdf.js 3.11.174 渲染引擎
lib/pdf.worker.min.js
```

## 安装

1. 地址栏打开 `edge://extensions/`
2. 右下角开启「开发人员模式」
3. 点「加载解压缩的扩展」，选择 `pdf-coord-edge` 文件夹
4. 扩展卡片 →「详情」→ 打开 **「允许访问文件 URL」**（测量本地 PDF 必需）

## 使用

- 在 Edge 里点开任意 `.pdf`（本地文件或网页链接），会自动跳到坐标查看器。
- 若没有自动跳转（例如已在内置阅读器里打开），点扩展图标 →「用当前标签页的 PDF 打开」；或右键 PDF 链接 →「用 PDF 坐标查看器打开」；或在查看器里点「选择文件」。
- 鼠标在页面上移动 → 顶部状态栏与跟随鼠标的浮层同时显示 `X / Y`。
- 单击页面可**打点**，打两个点后自动给出 `ΔX / ΔY / 直线距离`，按 `Esc` 或「清除标记」重置。
- 工具栏可切换：原点角（默认左下角）、单位（pt / mm / cm / in）、小数位、视图旋转、十字线、刻度尺、缩放、适应宽度。
- **`Ctrl` + 鼠标滚轮 = 组件内缩放**（以光标位置为中心，范围 20%–800%；触摸板捏合同效）。不会触发浏览器整页缩放，页面文字也不会被放大。未打开 PDF 时保留浏览器默认行为。
- 翻页：左右方向键、`PageUp/PageDown`，或页码输入框；滚动时当前页自动跟随。

## 坐标是怎么算准的

不猜屏幕 DPI，而是对每一页做自标定：

- `page.view` 给出该页在 PDF 用户空间的宽高，PDF 里 1 单位 = 1 pt；
- `getViewport({scale, rotation})` 给出该页当前显示的 CSS 像素宽高；
- 两者相除得到该页真实的 `px/pt` 比例，鼠标像素位置除以它就是 pt 坐标。

因此读数与显示缩放、浏览器缩放、屏幕分辨率、DPI 设置都无关；`Y` 轴做了翻转，使左下角为原点、向上为正。

## 说明与限制

- Edge 内置 PDF 阅读器属于浏览器内核页面，扩展**无法**向其注入脚本，所以本扩展用 pdf.js 自行渲染页面来获得鼠标事件与页面边界 —— 这也是坐标能做到准确的前提。
- 扫描版/图片型 PDF 没有文字层，只能测量坐标，不能选词复制。
- 超大文件（几十 MB、数百页）首次渲染会稍慢，因为默认一次渲染全部页面。
